# trip-planner

A day-by-day travel itinerary you can put on everyone's phone: one page with a tab per day, a route
map, printable PDFs, and an **installable app mode that keeps working with no signal**.

The example data is a cleaned copy of a real 12-day self-drive trip around Hokkaido, built with
Claude Code for a family that reads English and Traditional Chinese. Names, bookings, dates and the home
city have been removed.

- [PROCESS.md](PROCESS.md): how the original trip was planned, built, hosted, shared and retired.
- [OFFLINE.md](OFFLINE.md): how the installable offline mode works, what it saves, and what to check before a trip.

## What's in it

| | |
|---|---|
| **Itinerary** (`site/index.html`) | One file with no framework and no build step. A tab per day with a timeline of stops, the night's hotel, and an "Open in Google Maps" button on everything. English / 繁中 switch. |
| **Route map** (`site/map.html`) | Leaflet with every driving day's route in its own colour, pins for stops and hotels, and a day filter. |
| **PDFs** | Both languages, printed from the same page by headless Edge. |
| **Offline app** | Add to Home Screen, then "Save for offline" stores the pages, PDFs, fonts and the map along every route (about 19 MB for the example trip). |

```
site/                   everything that gets served
  index.html            the itinerary: TRIP data at the top, renderer below
  map.html              route map (reads map-data.js)
  map-data.js           generated by tools/make-map.cjs
  config.js             version, tile server, what "Save for offline" downloads
  offline.js            registers the service worker, offline badge, Save-for-offline panel
  sw.js                 service worker
  manifest.webmanifest  install name, colours, icons
  icons/                icon.svg + PNGs made by tools/make-icons.ps1
  vendor/leaflet/       Leaflet 1.9.4, kept locally so the map opens offline
tools/
  make-map.cjs          pins + driving routes -> site/map-data.js (routes from the OSRM demo server, cached)
  map-routes.json       the route cache
  make-pdfs.ps1         site/trip-en.pdf + site/trip-zh.pdf via headless Edge
  make-icons.ps1        icon.svg -> 192 / 512 / Apple touch PNGs
deploy/
  Caddyfile.example     static hosting with the right cache headers (optional password)
```

## Run it locally

```bash
python -m http.server 8767 -d site
```

Open <http://localhost:8767>. Service workers run on `localhost` without HTTPS, so the offline mode can be
tested there too (in Chrome DevTools: Application → Service workers, Cache storage, and Network → Offline).

## Make it your trip

1. **Itinerary:** edit the `TRIP DATA` block at the top of `site/index.html`. Every visible string can be
   plain text or `{ en: "...", zh: "..." }`. A stop is `{ icon, time, title, notes, map }`, where `map` is the
   Google Maps search text. Driving stops can carry `dir: [...]` route options (coast road vs expressway,
   with time and toll) as pinned coordinates. `HOTELS` holds each night's stay, and `SEALS` the red stamp
   on each day.
2. **Map pins:** in `tools/make-map.cjs`, give every place a coordinate in `P`, then list each driving
   day's pins and route in `DAYS`. Use coordinates, not names: a place name Google Maps can't match
   silently centres the map on the viewer, with no error.
3. **Build:**
   ```bash
   node tools/make-map.cjs --routes
   ```
   `--routes` re-fetches driving routes. Leave it off to reuse the cache.
   ```powershell
   powershell -ExecutionPolicy Bypass -File tools\make-pdfs.ps1
   ```
4. **App identity:** change `name` in `site/manifest.webmanifest`, redraw `site/icons/icon.svg` if you like,
   and run `tools\make-icons.ps1`.
5. **Every deploy:** bump `version` in `site/config.js` so phones replace their saved copy.

## Host it

Any static host with HTTPS works, because a service worker needs HTTPS. The original ran in a Caddy
container on a home server, published with Tailscale Funnel; see `deploy/Caddyfile.example`. Serve
`sw.js` and `config.js` with `Cache-Control: no-cache`, or phones keep running the old version.
